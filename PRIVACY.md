## 🔎 What This Document Covers

This document describes how GitHub Copilot Memories at https://github.com/hmlendea/github-copilot-memories handles personal data. It covers the repository content and verified integrations described below. The repository is a collection of instruction files, skills, and agents; it does not operate a hosted service or process user data.

## 📥 Data We Handle

### Data Provided to the Application

- No personal data is requested or collected by the repository content.

### Data Generated or Collected by the Application

- No personal data is generated or collected automatically by the repository content.

### Data Received from Integrations

- No personal data is received from integrations or third parties by the repository content.

## 🧭 Processing and Use

The repository content does not process personal data for any function.

## 🗄️ Storage, Retention, and Deletion

The repository content does not store, retain, or delete personal data.

## 🔗 External Processing and Integrations

The repository content has no built-in external data transfer. It references external services (GitHub, VS Code, OpenAI Codex) only through documentation links and installation instructions.
