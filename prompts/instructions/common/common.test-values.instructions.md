## Test Values

When writing, revising, or generating tests or test data in any language, framework, or technology, invoke the `test-values` skill and prefer its values over inventing new ones.

This rule applies to every test artefact, including inline tests inside production source files (e.g. Rust `#[cfg(test)]`, Go `_test.go`, C++ test blocks, Python `unittest`/`pytest`, Java/Kotlin, JavaScript/TypeScript, Ruby, PHP, C#, and shell test frameworks). Do not rely on test-file naming conventions to decide applicability.
