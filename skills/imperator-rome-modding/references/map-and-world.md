# Map and World Data

## Adding a Province

1. Paint a new province shape with a **unique colour** in `map_data/provinces.png`.
2. Register the RGB value with a new province number in `map_data/definition.csv`.
3. Attach it to the hierarchy:
   - Land province: add it to an area in `map_data/areas.txt`; if the area is new, add it to a region in `map_data/regions.txt`.
   - Impassable: list it under the impassable entries in `map_data/default.map`.
4. Give it setup data in `setup/provinces/<file>.txt` (terrain, culture, religion, trade good, pops, rank).
5. Generate map locators from the console:

```
mapobjects.generategamelocators fort
mapobjects.generategamelocators city
mapobjects.generategamelocators combat
mapobjects.generategamelocators port
mapobjects.generategamelocators unit_stack
```

Locators are written to `<user data>/Imperator/generated/`; move them to `<mod>/gfx/map/map_object_data/`.

Ownership is **not** set here — it belongs to the country block in `setup/main/`. Ports and adjacencies live in `map/`.

## Roads

- Regenerate the spline asset file with `SplineNetwork.GenerateAssets` in the console. Output lands in `<user data>/Imperator/gfx/map/roads/`. (Pre-2.0 the command was `roads.generateassets`; it no longer works.)
- Edit roads in the map editor's **Spline Network Strip Tool** (hotkey `9`):
  1. **Create new anchors** — one anchor per territory.
  2. Set each anchor's ID to the **territory id** with **Select and modify anchors**.
  3. **Create a strip between two anchors** — drag from anchor to anchor.
- Bridges and three-way junctions are generated by the strip tool, so order of placement affects the result. Adjust with **Spline Network Adjustment** (hotkey `Alt+9`).

## Surround Mask and Clouds

`gfx/map/surround_map/surround_mask.dds` controls the cloud surround.

Authoring recipe (Photoshop-style layering):

1. Fill the base layer with `#000000` — this is the empty canvas outside the map.
2. Copy `provinces.bmp`, scale to 50%, centre it in its own layer. It is a guide only and is removed at the end.
3. New layer above: fill `#FFFF00` — defines where **light** clouds appear.
4. On the yellow layer, erase (Pencil, 100% opacity/hardness) where you do **not** want light clouds.
5. Select the remaining yellow with the magic wand (tolerance 0, anti-alias off), create a new layer below the yellow, and fill the selection with white — defines **heavy** clouds.
6. Gaussian-blur the yellow and white layers to soften transitions.
7. Delete the `provinces.bmp` guide layer, merge black/yellow/white, save as `.dds`.

Square artefacts after the blur are tuned in `common/defines/graphic/00_graphics.txt`.

## Heightmaps

NASA Visible Earth provides suitable topography sources (the Imperator region corresponds to tiles B1 and C1 in the Visible Earth grid). Check the Visible Earth image-use policy before redistributing derived data.

## Map Modding Limits

Mapmodes, diplomatic actions, and hotkeys are hardcoded. Map changes require a full restart (no reload command); also expect the first launch after a map edit to be slow while locators and caches regenerate.

## Buildings

Buildings, forts, ports, roads, and border forts are defined in `common/buildings/`. Cities cannot exceed their building slot count, which is driven by province rank and pops. Forts exert a zone of control over adjacent territories; a hostile army entering a ZoC must reduce the fort before proceeding. Ports are tiles in the map data plus a building definition; a port grants its territory coastal access and a province-wide migration modifier, and multiple ports in one territory do not stack.
