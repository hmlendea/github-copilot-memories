---
name: session-handoff
description: Use when changing task, topic, model, reasoning effort, agent, or tool set, or when accumulated conversation context is no longer relevant.
---

Continue in a fresh session with a compact handoff:
- objective and acceptance criteria
- verified decisions and constraints
- modified files and current state
- validation commands and outcomes
- unresolved blocker or exact next action

Exclude transcript narration, superseded options, verbose tool output, secrets, and unrelated context. Attach only required files. Keep model, agent, and tool set stable within the new session.
