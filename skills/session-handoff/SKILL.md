---
name: session-handoff
description: "Use when changing task, topic, model, reasoning effort, agent, or tool set, or when accumulated conversation context is no longer relevant."
---

Continue in a fresh session with a compact handoff artefact, normally `HANDOFF.md`, holding:
- objective and acceptance criteria
- verified decisions and constraints
- modified files and current state
- validation commands and outcomes
- failed attempts, each with the approach and the reason it proved inadequate, so the next session does not repeat it
- unresolved blocker or exact next action, stated concretely enough to commence without this transcript

Exclude transcript narration, superseded options, verbose tool output, secrets, and unrelated context. Attach only required files. Keep model, agent, and tool set stable within the new session. Carry prior authorisation forward, and treat the handoff as conferring no new authority.
