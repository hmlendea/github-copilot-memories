# Mod Packaging, Manifests, Overrides, and Publishing

## Paths

| Purpose | Path |
|---------|------|
| Development mods | `%LOCALAPPDATA%\Feral Interactive\Total War ROME REMASTERED\Mods\Local Mods\<Mod Name>\` and `...\Mods\My Mods\<Mod Name>\` |
| Game data (read-only reference) | `<steam>\steamapps\common\Total War ROME REMASTERED\Contents\Resources\Data\` |
| Feral UI strings | `<install>\Contents\Resources\en.lproj\Localizable_Game.strings` |
| Virtual file system root | `%LOCALAPPDATA%\Feral Interactive\Total War ROME REMASTERED\VFS\Local\Rome\` |
| Logs | `...\VFS\Local\Rome\logs\` |
| Generated script dictionaries | `...\VFS\Local\Rome\documentation\docudemon_*.txt` |
| Preferences and `EnhancedTweaks` export | `%LOCALAPPDATA%\Feral Interactive\Total War ROME REMASTERED\` |
| Workshop subscription | `<steam>\steamapps\workshop\content\885970\<workshop id>\` |

If the system drive is full, relocate `Mods` with a directory hard link; the launcher has no built-in path setting.

**Long paths break loading.** Every mod file sits under a deep base path, so a long folder name plus long filenames plus leftover `- copy (2)` directories exceeds the OS limit. The symptom is a blank launch error with a yellow `!`. The mod-folder name is not the displayed mod name, so shorten it freely.

**Folder and file names are case-sensitive on Linux and macOS.** Match the vanilla case exactly.

## Mod Skeleton

```
<Mod Name>/
  modinfo.json        # written by hand
  filelist.json       # generated by the launcher
  data/               # mirrors Contents/Resources/Data
```

Both JSON files sit at the mod root, next to — not inside — `data/`.

## `modinfo.json`

Written by hand. Keys are case- and space-sensitive.

```json
{
  "Description": "Brief description of your mod goes here",
  "Mod Name": "Mod name goes here",
  "Preview Image": "ExampleMod.png",
  "Supports Alex": false,
  "Supports BI": false,
  "Supports Rome": true,
  "Tags": [],
  "Visibility": 1,
  "Workshop ID": 0
}
```

- `Supports Rome` / `Supports BI` / `Supports Alex` decide which base campaign accepts the mod. A BI mod that does not ship the BI-internal faction, culture, and religion names fails at load; either match them or ship every file that mentions them.
- `Tags` and `Visibility` feed the launcher and Workshop listing; leave them empty and `0`/`1` until publishing.
- `Preview Image` is a file in the mod root, not a full path.
- `Workshop ID` is written back by the launcher after the first upload; leave it `0`.

## `filelist.json`

The manifest. Generated by selecting the mod in the Feral launcher and pressing **Regenerate Manifest**.

```json
[
  {
    "filename": "data/export_descr_unit.txt",
    "checksum": 152007092
  }
]
```

- Only listed files load. Adding, renaming, deleting, or editing a file without regenerating leaves the mod reading the previous state — or, for new files, reading nothing at all.
- A missing manifest boots the vanilla game with no error.
- **A 0 KB file breaks manifest generation.** If a file must exist but carry no content, put a comment line in it. This commonly bites `descr_events.txt`, `descr_disasters.txt`, and empty campaign folders.
- `checksum_blacklist.txt` in the game data names file types that are excluded from checksum generation; do not fight it.

## Override Semantics

There is exactly one rule: **the same relative path replaces the whole vanilla file.** There is no merge, no append, no per-key override, and no `replace_path` equivalent. Consequences:

1. Copy the vanilla file into the mod at the identical relative path, then edit the copy.
2. Anything you delete from the copy is deleted from the game; anything you leave is inherited only because you left it.
3. A new file in the same folder is *not* merged with the vanilla file of the same domain — for most data files the engine reads one file per definition domain, so a new name is ignored.
4. Two mods shipping the same relative path conflict wholesale; the launcher decides which wins.

Prefer the smallest possible copied file when replacing, and prefer new uniquely named definitions inside a copied file over duplicating vanilla definitions.

## Toggles

`data/toggles/` carries the Classic-vs-Remastered switch system.

`toggles/toggle button states.txt` is the master list; each block names a toggle, whether the player may change it, and its default:

```
unit balancing
enabled :: 1
default :: 1
```

`1` = Remastered, `0` = Classic. Every toggle has two identically named files, one under `classic/` and one under `remastered/`; each line is `feature description` with `0` disabled and `1` enabled. Shipped files: `ai improvements.txt`, `battle.txt`, `camera.txt`, `campaign.txt`, `diplomacy.txt`, `end turn.txt`, `population balancing.txt`, `trade.txt`, `unit balancing.txt`.

Ship the folder inside a mod to lock a mod's ruleset: set `enabled :: 0` and the intended `default`. A mod may also flip individual features without touching the player-facing toggle.

Notable switches: `improved ai`, `improved battle ai`, `night battles`, `unlimited men`, `merchants`, `embargo`, `trade_anywhere`, `squalor effects`, `upkeep costs`, `ambushes`, `gradual trait loss`, `normalised pop reduction`, `hiding general`.

## `data_controlled_features.json`

Feature switches, all new in 2.0.4, with tunables in `data_controlled_variables.json`.

| Feature | Default | Effect |
|---------|---------|--------|
| `opaque_black_fow` | false | Opaque fog of war on terrain, minimap, and overlay |
| `region_name_in_tags` | true (disable to hide) | Region name under settlement tags |
| `public_order_bonuses` | — | Income scaling by public order; extra construction and recruitment points above a threshold |
| `type_specific_movement_point_modifiers` | false | Per-category/class movement on the campaign map from `feral_descr_movement_multipliers.txt` |
| `night_control` | false | Torch use driven by sun angle |
| `disable_friendly_fire` | false | No friendly fire in 3D battles |
| `disable_torch_allocation` | false | No torches at night while windows still light |

Variables: `order_income_bonus_start` (`120`), `order_income_bonus_multiplier` (`0.0025`), `order_construction_bonus_threshold` (`180`), `order_recruitment_bonus_threshold` (`180`), `torches_min_sun_angle` (`90.0`), `torches_max_sun_angle` (`265.95`).

## `string_overrides`

Text rendered by Feral's UI layer does not come from `data/text/`. It comes from `Contents/Resources/<lang>.lproj/Localizable_Game.strings`. Override it by copying that file into `data/string_overrides/<language code>.strings` — English is `en.strings`, and the same pattern holds for every shipped language.

`data/text/menu_english_stm.txt` (and its language variants) still supplies a separate slice of menu text; know which of the two owns the string before editing.

## Enhanced Tweaks

`enhanced_tweaks` in the launch options opens an in-engine IMGUI overlay for graphics variables. Exported JSON lands in `%LOCALAPPDATA%\Feral Interactive\Total War ROME REMASTERED\EnhancedTweaks` with separate files for main menu, campaign, and 3D battle. Copy the export into `data/enhanced_tweaks/`.

Two traps: the export contains resolution and quality settings you should delete before shipping, and the engine reads every text file in that folder regardless of extension, so leftover backups change behaviour.

## Publishing

Upload through the Feral launcher to the Steam Workshop (app `885970`). The launcher writes the assigned ID into `modinfo.json`. Regenerate the manifest immediately before every upload; an outdated manifest ships an outdated mod. Subscribers receive the folder verbatim under `steamapps/workshop/content/885970/<id>`, so keep the folder free of development artefacts and duplicate backups.

## Encoding and Failure Checklist

- Data files: ANSI/Windows-1252. A UTF-8 BOM corrupts the first key; multi-byte characters corrupt everything after them.
- JSON files: plain UTF-8, no comments — the parser is strict.
- Scripts: ANSI, tabs for indentation, `;` comment marker in data files, `;;` in script and in the shipped `.txt` data blocks.
- `.tga` in a data file usually resolves to `.tga.dds` on disk; the `.dds` is preferred when both exist.
- A mod that changes nothing: stale manifest, wrong base game, wrong case, UTF-8 BOM, 0 KB file, path length.
